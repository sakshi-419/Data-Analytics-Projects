# Netflix Data Analysis

## Objective

Analyze Netflix content data to understand trends in movies and TV shows, content distribution, ratings, genres, and release patterns.

## Tools Used

* Python
* Pandas
* Matplotlib

## Analysis Performed

* Data Cleaning
* Handling Missing Values
* Exploratory Data Analysis (EDA)
* Content Distribution Analysis
* Genre Analysis
* Ratings Analysis
* Release Year Trend Analysis
* Data Visualization

## Key Insights

* Analyzed the distribution of Movies and TV Shows on Netflix.
* Identified the most common content ratings.
* Explored content release trends over the years.
* Determined the most popular genres available on the platform.
* Visualized patterns in Netflix's content library.

## Skills Demonstrated

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Data Visualization
* Pandas
* Matplotlib
* Business Insights
