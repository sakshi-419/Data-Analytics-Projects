# Online Retail Sales Analysis

## Objective

Analyze online retail sales data to understand sales patterns, customer behavior, and product performance.

## Tools Used

* Python
* Pandas
* Matplotlib

## Analysis Performed

* Data Cleaning
* Handling Missing Values
* Exploratory Data Analysis (EDA)
* Sales Analysis
* Customer Analysis
* Product Analysis
* Data Visualization

## Key Insights

* Identified top-selling products.
* Analyzed customer purchasing patterns.
* Evaluated sales trends over time.
* Compared product performance using visualizations.
* Generated business insights from retail transaction data.

## Skills Demonstrated

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Data Visualization
* Pandas
* Matplotlib
* Business Insights
